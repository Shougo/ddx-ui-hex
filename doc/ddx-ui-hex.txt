------------------------------------------------------------------------------
FUNCTIONS                                               *ddx-ui-hex-functions*

                                                      *ddx#ui#hex#do_action()*
ddx#ui#hex#do_action({action-name}[, {params}])
		Fire {action-name} action with {params}.  You can find the
		actions list in |ddx-ui-hex-actions|.
		{args} behavior depends on {action-name}.
		NOTE: It can be called in the filter window or UI window.


------------------------------------------------------------------------------
ACTIONS                                                   *ddx-ui-hex-actions*

                                                    *ddx-ui-hex-action-change*
change
		Change the value in current address.
		If the address is selected, ranged values are changed.

		params:
			{type}: Value type.

				"hex": hexa decimal string (Default)
				"string": string

                                                  *ddx-ui-hex-action-checksum*
checksum
		Print checksum value.
		The address must be selected.

		params:
			{method}: Checksum method.

				"sum": Simple sum (Default)
				"md5": MD5

                                                      *ddx-ui-hex-action-copy*
copy
		Copy current address value.
		If the address is selected, ranged adress is copied.

                                                    *ddx-ui-hex-action-insert*
insert
		Insert the value in current address.

		params:
			{type}: Value type.

				"hex": hexa decimal string (Default)
				"string": string

                                                  *ddx-ui-hex-action-nextDiff*
nextDiff
		Search the changed address from current address.

                                                     *ddx-ui-hex-action-paste*
paste
		Paste previous removed values.

                                                      *ddx-ui-hex-action-quit*
quit
		Quit the UI window.

                                                      *ddx-ui-hex-action-redo*
redo
		Undo the last undo.
		NOTE: You cannot change the undo if you have changed buffer.

                                                    *ddx-ui-hex-action-remove*
remove
		Remove current address value.
		If the address is selected, ranged adress is removed.

                                                    *ddx-ui-hex-action-search*
search
		Search the value from current address.

		params:
			{type}: Value type.

				"hex": hexa decimal string (Default)
				"string": string

                                                      *ddx-ui-hex-action-save*
save
		params:
			{path}: Save filename path.

		Save current buffer to {path}.
		If {path} is empty, the opened file path will be used.

                                             *ddx-ui-hex-action-selectAddress*
selectAddress
		Select current address.
		If it is already selected, it is unselected.

                                                      *ddx-ui-hex-action-undo*
undo
		Undo the last change.

                                                      *ddx-ui-hex-action-yank*
yank
		Yank the value in current address.

		params:
			{type}: Value type.

				"hex": hexa decimal string (Default)
				"string": string

==============================================================================
PARAMS                                                     *ddx-ui-hex-params*

                                                   *ddx-ui-hex-param-encoding*
encoding	(string)
		Specify encoding.
		NOTE: Both "utf-8" and "cp932" are supported.

		Default: "utf-8"

                                             *ddx-ui-hex-param-floatingBorder*
floatingBorder		(string | list)
		Specify the style of the window border if
		|ddx-ui-hex-param-split| is "floating".
		See |nvim_open_win()| for the detail.
		NOTE: It is neovim only.

		Default: "none"

                                                 *ddx-ui-hex-param-highlights*
highlights	(dictionary)
		It specifies ddx-ui-hex buffer highlights.
		It can contain following keys
		NOTE: It is slow.

		ascii			(string)
		Specify ASCII code highlight.
		Default: ""

		changed			(string)
		Specify changed address highlight.
		Default: "ErrorMsg"

		control			(string)
		Specify control code highlight.
		Default: ""

		cursorAscii		(string)
		Specify cursor ascii area highlight.
		Default: "Search"

		diffAdd			(string)
		Specify diff added highlight.
		Default: "DiffAdd"

		diffChange		(string)
		Specify diff changed highlight.
		Default: "DiffChange"

		diffDelete		(string)
		Specify diff deleted highlight.
		Default: "DiffDelete"

		escape			(string)
		Specify escape code highlight.
		Default: ""

		newLine			(string)
		Specify new line code highlight.
		Default: ""

		null			(string)
		Specify null byte code highlight.
		Default: ""

		selected		(string)
		Specify selected address highlight.
		Default: "Visual"

		tab			(string)
		Specify tab code highlight.
		Default: ""

		floating			(string)
		Specify floating window background highlight.
		Default: "NormalFloat"

		Default: {}

                                        *ddx-ui-hex-param-overwriteStatusline*
overwriteStatusline (boolean)
		If it is true, the original 'statusline' value is set on the
		buffer.

		Default: v:true

                                             *ddx-ui-hex-param-overwriteTitle*
overwriteTitle	(boolean)
		If it is true, the original 'titlestring' value is set on the
		buffer.

		Default:
			v:false
			v:true (When 'laststatus' is 0)

                                                      *ddx-ui-hex-param-split*
split		(string)
		Specify split mode. Following values are available:

		"horizontal": horizontal split
		"vertical": vertical split
		"floating": use neovim floating window feature
		"no": no split

		Default: "horizontal"

                                             *ddx-ui-hex-param-splitDirection*
splitDirection	(string)
		Specify split direction.

		Default: "botright"

                                                     *ddx-ui-hex-param-winCol*
winCol		(number)
		Set the column position of the window if
		|ddx-ui-hex-param-split| is "floating".

		Default: &columns / 4

                                                  *ddx-ui-hex-param-winHeight*
winHeight	(number)
		Set the height of the window if |ddx-ui-hex-param-split| is
		"horizontal".
		if |ddx-ui-hex-param-split| is "floating",
		set the height of the floating window.

		Default: 20

                                                     *ddx-ui-hex-param-winRow*
winRow		(number)
		Set the row position of the window if |ddx-ui-hex-param-split|
		is "floating".
		If it is 1, the filter window position is always top.

		Default: &lines / 2 - 10

                                                   *ddx-ui-hex-param-winwidth*
winWidth	(number)
		Set the width of the window if |ddx-ui-hex-param-split| is
		"vertical".
		if |ddx-ui-hex-param-split| is "floating", set the width of
		the floating window.

		Default: &columns / 2


==============================================================================
EXAMPLES                                                 *ddx-ui-hex-examples*
>vim
	call ddx#custom#patch_global({
	    \   'ui': 'hex',
	    \ })

	autocmd FileType ddx-hex call s:ddx_hex_my_settings()
	function s:ddx_hex_my_settings() abort
	  nnoremap <buhexer> q
	  \ <Cmd>call ddx#ui#hex#do_action('quit')<CR>
	  nnoremap <buhexer> r
	  \ <Cmd>call ddx#ui#hex#do_action('change')<CR>
	endfunction
<
